# Examples

This folder demonstrates the smallest runnable form of a DataDiddler lens repo.

## Quick example

Run:

```bash
python -m lens_template.lens --in examples/sample_in/input.txt --out-dir examples/sample_out
```

Expected output:

```text
examples/sample_out/lens_output.ndjson
```

## Purpose

The example is intentionally tiny.

It exists to show:

- how a lens is invoked
- where outputs go
- what a minimal proof surface looks like
